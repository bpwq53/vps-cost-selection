## 算清三个数字再看性价比：续费价、流量、隐藏费用

判断一台 VPS 值不值，看三个数字就够了：续费价、流量额度和隐藏费用。首月标价只是广告位。

续费价是第一个要查的。CloudsPress 收录的 391 家 VPS 商家里，挂牌入门价中位数 $9.95/月，续费价中位数 $11.46，涨 15% 左右是常态。极端案例如 BuyVPS：S-2 套餐首月 $1，续费 $7.99，翻了近八倍。公布续费价的 52 家里只有 19 家承诺续费不涨价，当然也确实有商家首购续费同价（比如 VPSRENTO 的入门套餐一直是 $3/月），所以下单前专门去找一句“续费同价”，找不到就开工单问。

流量是第二个。Hetzner 一档就给 20TB，DigitalOcean 和 Vultr 的主流档含 5–6TB，入门小机则往往只有 500GB；Lightsail 流量超量按 $0.09/GB 计费——真跑出一个 20TB 出口量的站，光超量费就够再租几台服务器。做媒体站、下载站之前先算这笔账。

第三个是藏在条款里的费用，几个常见的：

- 计划备份：DigitalOcean 按实例价格的 20% 收费；Hetzner 快照 €0.012/GB/月，自动保留 7 天
- 块存储扩容：DO 和 Linode 约 $0.10/GB/月，Hetzner Volume 约 €0.044/GB，差了一倍
- 计费方式：DO、Vultr、Linode、Hetzner 都按小时计费、封顶月价，开台测试机跑一天只要几美分；Hostinger、InterServer 只能整月付，试错成本高不少

这三项加在一起，往往比 CPU 快慢更影响你每月实际掏多少钱。

## 按场景对号入座

直接给规则：

- 个人博客、低流量站点：1GB 内存起步够用；WordPress 装了 WooCommerce、后台还常开的话，内存给到 4GB 起，否则高峰期 swap 到磁盘，体感比虚拟主机还慢

## 常见问题

**$4/月的 VPS 真能用吗？**
能，但有边界。512MB 内存跑静态站、监控脚本、轻量 bot 没问题；跑 WordPress 就勉强了，1GB 在插件一多时也会 swap。这个价位的正确用法是把它当“功能机”，别当主力。

**IPv6-only 的 $2.50 机器是什么限制？**
没有 IPv4 地址。大量网站和服务目前仍只有 IPv4，你的服务器主动访问它们会失败，别人也没法用 IPv4 直连你。套一层支持 IPv6 回源的 CDN 能绕开部分问题，但多一层配置就多一层维护负担。即便如此，它仍是市场上最便宜的正经 VPS。

**共享 CPU 和独享 CPU 差距有多大？**
基准成绩差 30%–50%（1,912 对 2,841 events/sec），更要命的是高峰期的 CPU steal：Pickly 的对比测试里，Linode 和 AWS 的共享实例在高峰时段有可见的性能被抽走，DigitalOcean Premium 和 Hetzner CPX 这类独享核方案接近零。跑定时任务无所谓，跑在线服务差别明显。

**小商家会不会说跑就跑？**
任何商家都有风险，大厂也出过事故——Lightsail 曾在 60 天内出现两次 90 分钟以上的故障。你能做的是控制敞口：月付、快照或备份常开、重要数据异地再存一份。
